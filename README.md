Pada modul minggu pertama ini, saya mempelajari dasar-dasar pengembangan web menggunakan kombinasi HTML, CSS, dan framework Bootstrap 5. Fokus pembelajaran hari ini adalah memahami struktur dasar halaman web, cara menghubungkan file CSS eksternal, serta memanfaatkan sistem grid dan komponen siap pakai dari Bootstrap (seperti Navbar dan Card) untuk membuat layout yang rapi dan responsif dengan cepat.

Secara teknis, proyek ini merupakan tampilan front-end sederhana untuk "Sistem Manajemen Sepatu". Kode HTML dibangun menggunakan class-class Bootstrap untuk menyusun elemen menjadi kolom yang teratur, mulai dari navigasi, statistik dashboard, hingga galeri produk. File CSS tambahan (style.css) bekerja untuk menangani kustomisasi yang lebih spesifik, seperti menampilkan gambar latar pada hero section dan memberikan efek animasi zoom saat kursor diarahkan ke kartu statistik.
